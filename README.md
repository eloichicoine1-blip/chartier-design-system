# Bouillon Chartier · Design System (HTML/CSS)

Page statique du Design System du site click & collect Bouillon Chartier.
SAé 3.01, BUT MMI 2, Création Numérique, IUT du Limousin. Eloi Chicoine.

- `index.html` : la page (couleurs, typographie, espacements, boutons, badges, formulaires, cartes, navigation, messages)
- `style.css` : reset Piccalilli, variables primaires (valeurs Figma), variables secondaires (rôles), composants en BEM
- `assets/` : logos SVG et photos produits

Sans framework (pas de Tailwind), sans JavaScript.
Maquettes et variables d'origine : fichier Figma « SAE312 2026 ».

Projet pédagogique, non affilié à Bouillon Chartier.
